# Accueil Senior — Expo

Petit écran d'accueil React Native Expo en TypeScript pour une expérience senior très lisible.

## Contenu

- deux actions principales sans défilement ;
- un bouton géant pour les médicaments ;
- un bouton géant rouge pour l'urgence ;
- textes français avec tailles de police de 24 px et plus ;
- composant `SeniorActionButton` réutilisable ;
- configuration Expo isolée du projet Next.js principal.

## Lancer l'écran

```bash
cd mobile/senior-home
npm install
npm run start
```
